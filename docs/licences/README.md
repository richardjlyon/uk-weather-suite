# Licence records

Every external data source used by this project has its terms recorded
verbatim with a retrieval date, because the pre-registration deposit can
only carry what we are entitled to redistribute. Copies here are tracked
in git; the originals sit beside their data under `data/*/LICENCE-NOTE.md`
(gitignored).

| source | licence | may derived values be deposited? |
|---|---|---|
| MIDAS Open (CEDA) | Open Government Licence | yes |
| GHSL (JRC) | free reuse with acknowledgement | yes |
| Natural England SSSI/NNR | Open Government Licence | yes |
| OpenStreetMap aeroway | ODbL, attribution required | yes, with attribution |
| ONS census + Open Geography | OGL | yes |
| EA Digital Land Utilisation Survey | EA Conditional Licence, **non-commercial**, © Audrey N. Clark | derived per-station values only, never source imagery |
| NLS historic maps | stated variously CC-BY 3.0 / CC-BY-SA 3.0 / non-commercial — **unverified** | treat as non-redistributable until confirmed; deposit viewer permalinks instead of pixels |
| GB Historical GIS parish data | not obtained — withdrawn from distribution; boundary geometry is special-request only, not-for-profit | n/a |

The governing position, adopted 2026-07-29 after the Scotland review
found the earlier framing incoherent: **source choice is driven by
fitness; licence drives what is deposited.** Per-station derived facts
are deposited; source imagery and full-resolution derivatives are not.
